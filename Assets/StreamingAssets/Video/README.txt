《地球重塑计划》剧情视频目录
================================

视频文件按以下文件名放入本目录后，VideoManager 会自动切换为真实播放
（无需修改任何代码）。文件缺失时流程自动使用占位卡并继续推进。

  ending_teaser.mp4   结局引入视频（冷开场 / 结局预告）
  ending_prequel.mp4  结局前奏视频（最终抉择前，存在则替换叙事卡）
  ending_terminate.mp4  结局A·终止重塑计划 独立结局视频
  ending_sacrifice.mp4  结局B·牺牲完成最终校准 独立结局视频
  opening.mp4         正序视频（当前由 FrontEnd 叙事卡呈现，接入后替换叙事入口）
  act_one.mp4         第一幕视频
  holiday.mp4         休假视频（当前由 FrontEnd 返航叙事卡呈现）

格式建议：H.264 / AAC 编码的 .mp4，分辨率 1280x720 或 1920x1080。
